## 关于

信息管理与信息系统本科在读，2027 年秋开始读软件工程硕士。方向还在试着找——靠不断试错，而不是靠提前规划；agent 的出现把试错的成本压低了一大截。

产出分两类：竞赛那边是算法（故障检测、多目标路径优化、市场调查分析），课程那边是系统（从挖雷小游戏到成绩管理、校园信息管理）。都在下面的项目表里。

现在重心转到 agent：自己天天用，也在为生态出力——写 pi 扩展，给在用的扩展提 issue 或 PR。

**如今**：pi 作为主力 agent · 试着 work-life balance · 折腾 minihub

→ [博客](https://vasantlong.de5.net/) · [笔记](https://notes.vasantlong.de5.net/)

## 我在折腾什么

- **pi 生态** —— 自用扩展：状态栏、完成通知、飞书远程桥，顺手给在用的扩展提 issue 或 PR。
- **minihub** —— Ubuntu 主机当服务器：Tailscale 组网、Gitea 自托管、Immich 相册同步、Zotero 附件 WebDAV、MinIO 对象存储，restic 定期备份并做过一次还原演练。
- **配置同步** —— 以 Gitea 仓库为真相源，各设备保留自己的定制，定时拉取。
